# fmap

Find Me A Property: a property-research business run as one pipeline. Design in `docs/architecture.md`; how to run and extend it in `.claude/skills/fmap-pipeline/SKILL.md`.

- Python 3.11+, standard library only. Tests: `python3 -m unittest discover -s tests`.
- The repo is public. Private inputs, outputs and lead data stay out of git (see `.gitignore`).
- Compliance rules: `docs/strategy/compliance.md`. Research, not advice; sales go through a MahaRERA-registered agent.
